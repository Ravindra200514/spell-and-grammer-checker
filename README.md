# Language Assistant (Spell & Grammar Checker and Translator)

A modern, fast, and beautifully designed web application built with React and Vite that provides powerful language tools, including a translation service and a spelling & grammar checker.

## Features

- **Translation Service:** Translate text between multiple languages (English, Spanish, French, German, Hindi) seamlessly.
- **Spell & Grammar Check:** Detect mistakes in your text and get context-aware corrections using the LanguageTool API.
- **Premium Design:** Features a sleek dark theme with a glassmorphism navigation bar, smooth micro-animations, and modern typography.
- **Responsive Layout:** Works flawlessly across desktops and mobile devices.

## Tech Stack

- **Frontend:** React.js, React Router DOM
- **Build Tool:** Vite
- **Styling:** Custom CSS with CSS Variables and Flexbox

## Getting Started

Follow these steps to run the application locally on your machine.

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Ravindra200514/spell-and-grammer-checker.git
   ```

2. Navigate to the project directory:
   ```bash
   cd spell-and-grammer-checker
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open your browser and navigate to `http://localhost:5173`.

## Usage

- **Home:** Overview of the application.
- **Spell & Grammar:** Type or paste your English text to get grammar and spelling suggestions.
- **Translation:** Select a target language and input text to get an instant translation.
